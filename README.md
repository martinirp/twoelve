# TwoElve

Automação para plataforma **Elleven** (ERP `erp.elo.net.br`).

- **Versão:** 6.0.0
- **Manifest:** Chrome MV3

## O que faz

- Botões e atalhos na toolbar do ERP (visitas, mensagens, encaminhamentos, automaticidades)
- Modais centralizados com tema "aço escovado" estilo Tibia
- Página de **Configurações** (`⚙️`): tema, fonte, opacidade, cores da interface, botões, emotes
- Exportar / importar dados e configurações
- **ATUALIZAR**: baixa a versão mais recente deste repositório e substitui a extensão local através de um instalador

## Instalação / atualização manual

1. Baixe o ZIP da branch desejada ou use o botão **🚀 ATUALIZAR** dentro das Configurações.
2. Extraia o ZIP (a pasta interna `twoelve-main/` contém os arquivos).
3. Substitua os arquivos na pasta da extensão.

## Instalação como extensão (Chrome)

1. Abra `chrome://extensions`.
2. Ative o **Modo do desenvolvedor** (canto superior direito).
3. Clique em **Carregar sem compactação** e selecione a pasta da extensão.
4. Recarregue a página do ERP.
