Visão Geral da Arquitetura

O TwoElve é uma extensão Chrome que injeta uma toolbar flutuante em qualquer página da plataforma Elleven. Cada botão da toolbar abre um modal específico. A v6.0 consolidou toda a lógica de modais em uma única classe base, resolvendo conflitos de duplos listeners, toggle inconsistente e botão X com comportamento errado.

Manifest.json — Ordem de Carregamento

A ordem dos scripts no manifest.json é crítica. Cada arquivo depende do anterior já estar executado. Trocar a ordem causa erros de "TwoelveModalBase is not defined" ou "abrirConfig is not a function".

manifest.json
{
  "manifest_version": 3,
  "name": "TwoElve v6.0",
  "version": "6.0.0",
  "description": "Automação para plataforma Elleven",
  "permissions": ["storage"],
  "host_permissions": ["<all_urls>"],
  "content_scripts": [
    {
      "matches": ["<all_urls>"],
      "js": [
        "modalbase.js",  // 1º — define window.TwoelveModalBase
        "button.js",     // 2º — injeta estilos de botão
        "config.js",     // 3º — define window.abrirConfig
        "sidebar.js",    // 4º — cria toolbar, conecta botões
        "visit.js",      // 5º — define window.abrirModalVisitas
        "messages.js",   // 6º — mensagens rápidas
        "forward.js",    // 7º — lógica de encaminhamento
        "utils.js",      // 8º — auto-login, roteadores, TwoElveControle
        "auto.js",       // 9º — monitoramento de abas / saudação
        "content.js"     // 10º — suporte geral, overlay de nome
      ],
      "run_at": "document_end"
    },
    {
      "matches": ["https://elonet.native-infinity.com.br/*"],
      "js": ["call.js"],
      "run_at": "document_end"
    }
  ]
}

Ciclo de Vida — Abertura e Fechamento de Modal

Entender exatamente o que acontece em cada clique é essencial para depurar e para criar novos módulos corretamente.

Fluxo: Usuário clica em "✅ Suporte" (modal fechado)

1. sidebar.js — listener do botão

O clique dispara o listener registrado no document_end. Ele chama gerenciarModal(() => window.abrirModalSuporte()).

2. gerenciarModal — verifica estado

modalAberto === null, então prossegue. Faz await funcaoAbrir(), aguardando a Promise de abrirModalSuporte.

3. content.js — abrirModalSuporte()

Carrega botões do storage (await carregarCustomButtons()), cria new TwoelveModalBase('✅ Botões de Suporte'), armazena em modalAtivo, chama modal.abrir().

4. TwoelveModalBase.abrir()

Cria o DOM do modal (container, header, título, botão X, body). Registra window._ultimoModalAberto = this. Adiciona ao document.body. Ativa drag no elemento do título.

5. gerenciarModal — captura referência

Após o await retornar, lê window._ultimoModalAberto e armazena em modalAberto. Encadeia no onFechar para zerar modalAberto quando o modal fechar.

6. Modal visível

O modal está no DOM, modalAberto no sidebar aponta para a instância, modalAtivo em content.js também. Ambos prontos para fechar.

Fluxo: Usuário clica em "✅ Suporte" novamente (toggle — modal aberto)

1. gerenciarModal — verifica estado

modalAberto !== null. Chama modalAberto.fechar() e seta modalAberto = null. Retorna sem abrir nada.

2. TwoelveModalBase.fechar()

Remove os event listeners de drag. Remove this.container do DOM. Dispara this.onFechar() se definido.

3. onFechar — limpeza em cascata

O callback encadeado pelo sidebar zera modalAberto = null. O callback original do módulo (setFecharCallback) zera modalAtivo = null. Estado limpo.

Fluxo: Usuário clica no botão X

modalbase.js — evento do X
// closeBtn.onclick: chama this.fechar() diretamente na instância
this.closeBtn.onclick = (e) => {
    e.stopPropagation();   // impede propagação para o header
    e.preventDefault();
    this.fechar();         // dispara fechar() na instância
};

// fechar() lê this.onFechar — que foi sobrescrito pelo sidebar
fechar() {
    if (this.container) {
        this._removeDragEvents();
        this.container.remove();
        this.container = null;

        if (this.onFechar) {
            this.onFechar();  // dispara callback encadeado → zera modalAberto
        }
    }
}

Por que o X funcionava com 2 cliques antes? Havia dois listeners no botão Suporte: um do sidebar e um da conectarComToolbar() em content.js. O primeiro clique no X fechava o modal, mas o segundo handler tentava abrir de volta. O segundo clique "cancelava" essa reabertura. Solução: remover conectarComToolbar() completamente.

modalbase.js — Classe Base

Define window.TwoelveModalBase, a única classe usada para criar modais em toda a extensão. Encapsula criação de DOM, estilo, drag e callbacks.

Estrutura do DOM gerado

DOM
<!-- Inserido em document.body -->
<div class="twoelve-modal-container">

  <div class="twoelve-modal-header">

    <div class="twoelve-modal-title">        <!-- cursor: move; drag ativo -->
      📌 Título do Modal
    </div>

    <button class="twoelve-modal-close">    <!-- X — stopPropagation no mousedown -->
      ✕
    </button>

  </div>

  <div class="twoelve-modal-body">
    <div class="twoelve-modal-content">   <!-- área de conteúdo -->
      <!-- innerHTML ou elemento DOM inserido aqui -->
    </div>
  </div>

</div>

API completa

new TwoelveModalBase(titulo?)

Cria uma nova instância. Não abre o modal ainda — apenas inicializa o objeto.

titulo string? Texto do cabeçalho. Pode incluir emoji. Padrão: 'TwoElve'.
método modal.abrir() → this

Cria o DOM do modal, insere em document.body, ativa o drag no título e registra window._ultimoModalAberto = this. Se o modal já estiver aberto, chama fechar() antes de reabrir (proteção contra dupla abertura). Retorna this para encadeamento.

método modal.fechar() → this

Remove event listeners de drag de window, remove o container do DOM, dispara onFechar() e desregistra de window._ultimoModalAberto. Retorna this.

método modal.setConteudo(html) → this

Define o conteúdo do corpo do modal usando uma string HTML. Útil para estruturas estáticas ou injetadas diretamente.

html string HTML a ser atribuído a .twoelve-modal-content via innerHTML.
método modal.setConteudoElemento(el) → this

Define o conteúdo usando um nó DOM real. Excelente para manter referências a listeners JavaScript anexados.

el HTMLElement Elemento DOM a ser inserido. Limpa o corpo antes de inserir.
método modal.setFecharCallback(fn) → this

Registra uma função a ser chamada quando o modal for destruído (pelo botão X, pelo toggle da barra ou por fechamento manual programático).

fn function Callback executado em fechar().
método modal.setTitulo(titulo) → this

Altera dinamicamente o título exibido no cabeçalho do modal sem precisar fechar ou reconstruir.

titulo string Novo texto/HTML do cabeçalho.

Regras de Estilo Padrão em modalbase.js

O arquivo define estilos padrão aplicados a qualquer elemento inserido no corpo do modal:

  • Inputs, Textareas e Selects têm fundo cinza claro (#cccccc) e borda de 2px preta para contraste.
  • Ao receber foco (:focus), ganham borda verde (#10b981).
  • Todo texto é herdado da fonte configurada em `config.js` via variáveis CSS no `:root`.

button.js — Padrão Visual Neubrutalista

O [button.js](button.js) padroniza o visual de todos os botões que aparecem em modais criados pela extensão. Ele garante a consistência visual do Neubrutalismo.

Classes Disponíveis

  • .twoelve-button: Botão padrão (fundo branco, borda de 2px preta, sombra sólida preta de 3px).
  • .twoelve-button-primary: Botão de ação positiva (fundo verde #10b981, texto branco).
  • .twoelve-button-danger: Botão de ação destrutiva (fundo vermelho #ef4444, texto branco).
  • .twoelve-modal-close: Botão de fechar (fundo branco, menor, sem herança de reset de botões gerais).

Comportamentos Visuais

  • Hover geral: Fundo listrado animado (cinza e cinza escuro), borda muda para verde #10b981, o botão se move -2px em diagonal e a sombra cresce para 5px.
  • Hover no Primary: Fundo muda para verde escuro #059669.
  • Hover no Danger: Fundo muda para vermelho escuro #dc2626.
  • Active (Clique): O botão se move +1px em diagonal e a sombra encolhe para 1px, dando a sensação física de pressionamento.

Comportamento do Grid

A classe .twoelve-buttons-grid organiza botões em colunas responsivas que se ajustam automaticamente ao tamanho do modal. Ela usa CSS Grid:

CSS Grid
.twoelve-buttons-grid {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(140px, 1fr));
    gap: 12px;
    padding: 4px;
}

sidebar.js — Painel de Controle e Toggle Único

O [sidebar.js](sidebar.js) é o coração organizacional da extensão. Ele cria a barra de ferramentas flutuante no topo e garante que nunca existam dois modais abertos ao mesmo tempo.

Código do Gerenciador de Modais

A função gerenciarModal() gerencia o estado global de modal aberto:

sidebar.js — gerenciarModal
let modalAberto = null;

async function gerenciarModal(funcaoAbrir) {
    // 1. Se já existe um modal aberto, fecha ele e encerra o fluxo
    if (modalAberto) {
        modalAberto.fechar();
        modalAberto = null;
        return;
    }
    
    // 2. Se não há modal aberto, chama a função para abrir o novo
    await funcaoAbrir();
    
    // 3. Captura a instância que se registrou globalmente ao abrir
    if (window._ultimoModalAberto) {
        modalAberto = window._ultimoModalAberto;
        
        // 4. Intercepta o callback de fechamento para limpar a variável local
        const callbackOriginal = modalAberto.onFechar;
        modalAberto.onFechar = () => {
            modalAberto = null;       // limpa referência local
            if (callbackOriginal) callbackOriginal();  // chama limpeza do módulo
        };
    }
}

Configuração de Emotes

Lê a chave twoelveConfig do storage local. Se usarEmotes for false, remove emojis dos botões da barra, mantendo apenas o texto limpo (ex: "Utils" em vez de "🛠️ Utils"). A barra reage em tempo real quando o usuário salva as configurações no modal Config.

visit.js — Controle de Visitas Técnicas

O [visit.js](visit.js) gerencia a criação, edição e preenchimento de visitas técnicas ou solicitações de mudança de endereço.

Lógica de Preenchimento Automático de Endereço

Ao executar uma visita do tipo "mudança", a extensão procura os inputs correspondentes no formulário ativo da plataforma Elleven:

visit.js — preencherEndereco
const ruaEl = await waitForElement('input#publicPlace', 5000);
if (ruaEl) setValue(ruaEl, rua);

const numeroEl = await waitForElement('input#number', 3000);
if (numeroEl) setValue(numeroEl, numero);

const bairroEl = await waitForElement('input#neighborhood', 3000);
if (bairroEl) setValue(bairroEl, bairro);

O campo **Contexto** no modal de execução de visitas é renderizado como **Apenas Leitura (disabled)** para garantir que o usuário preencha o contexto original definido no template do botão, mantendo a consistência dos dados inseridos.

content.js — Automação de Suporte e Cópia Rápida

O [content.js](content.js) automatiza ações em formulários da plataforma Elleven e injeta recursos úteis na tela do cliente.

Automação de Formulário

Bugs Conhecidos e Corrigidos na v6.0

RESOLVIDO
Botão X exigindo dois cliques para fechar o modal

Causa: Duplicidade de event listeners. Tanto sidebar.js quanto content.js ouviam cliques nos mesmos botões da barra para abrir/fechar os modais, gerando conflito de estado.

Solução: Remoção completa da função conectarComToolbar de todos os módulos. A barra é a única responsável por iniciar a abertura ou fechamento de modais.

RESOLVIDO
Salto (pulado) de posição ao arrastar o modal

Causa: Uso de offsetLeft e offsetTop para calcular posições iniciais durante o arrasto, gerando pulos visuais por desconsiderar margens e transformações CSS.

Solução: Alterado para usar getBoundingClientRect() no início do clique para obter coordenadas exatas relativas à viewport.

RESOLVIDO
Arrasto acionado ao clicar no botão X ou selecionar campos

Causa: Listener de arrasto no cabeçalho não verificava a origem do clique, iniciando o arrasto mesmo quando o usuário tentava fechar a janela.

Solução: Adicionado e.stopPropagation() e verificação no listener para ignorar cliques vindos do botão de fechar.

Padrão de Código para Novos Módulos

Ao criar novos arquivos ou funcionalidades que precisem abrir uma janela na extensão, siga o padrão de encapsulamento:

Template de Módulo
(function() {
    let modalAtivo = null;

    async function abrirModalExemplo() {
        if (modalAtivo) {
            modalAtivo.fechar();
            modalAtivo = null;
            return;
        }

        // 1. Cria a instância
        const modal = new TwoelveModalBase('💡 Novo Recurso');
        modalAtivo = modal;
        modal.abrir();

        // 2. Monta o conteúdo via DOM ou String
        const content = document.createElement('div');
        content.innerHTML = '<p>Conteúdo do recurso...</p>';
        modal.setConteudoElemento(content);

        // 3. Configura callback de limpeza
        modal.setFecharCallback(() => {
            modalAtivo = null;
        });
    }

    // 4. Expõe a função para o sidebar.js
    window.abrirModalExemplo = abrirModalExemplo;
})();
